## 🏭 部门定位

**数智化装备部门** 是在非标自动化业务基础上，向"软硬一体、数智赋能"方向升级转型的核心载体。

核心使命：**以数字化、智能化技术为非标装备赋能，构建差异化竞争优势，打开新的市场空间**
