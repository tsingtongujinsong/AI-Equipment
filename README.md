## 🏭 部门定位

**数智化装备部门** 是子公司非标装备业务的数智化赋能载体，重点负责软件、数据、算法、平台、工具与服务能力建设。

核心使命：**以数字化、智能化技术为非标装备业务赋能，提升方案竞争力、交付效率和服务价值，而不是承担装备本体的产品战略**
