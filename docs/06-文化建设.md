# 文化建设

## 文化目标

从“加工思维”转向“客户价值 + 技术驱动 + 结果导向”，打造可持续成长的学习型团队。

## 文化关键词

- 客户导向：所有决策围绕客户业务价值
- 技术务实：追求可落地、可复用、可维护
- 协同作战：打破软硬件和部门边界
- 结果负责：对目标、承诺、交付结果负责
- 持续学习：快速迭代、主动复盘、长期进化

## 行为准则（Do / Don’t）

### Do

- 用数据与事实沟通，不凭经验拍脑袋
- 关键问题当天暴露、当天建账、闭环跟踪
- 方案先考虑复用，再考虑定制
- 复盘聚焦问题与改进，不做责任甩锅

### Don’t

- 只关注短期签单，忽视长期可复制能力
- 为“看起来先进”牺牲交付稳定性
- 信息封闭与跨团队壁垒
- 过程无标准、结果不可追溯

## 文化落地机制

- 双周技术分享会：沉淀最佳实践与失败案例
- 月度客户之声会议：同步客户反馈与改进动作
- 项目AAR复盘：项目结束后7天内完成复盘
- 季度文化体检：通过问卷+访谈识别文化偏差
- 半年创新日：跨角色协作解决真实业务问题

## 文化融入管理场景

- 招聘：将文化匹配度纳入录用评估
- 绩效：将协作、复盘、知识沉淀纳入考核
- 晋升：将“带团队成长”作为晋升必要条件
- 奖励：对客户成功、跨团队协作与复用贡献设专项激励

## 文化健康度指标

- 客户满意/NPS趋势
- 项目复盘完成率与改进关闭率
- 跨团队协作满意度
- 知识库贡献度与复用率
- 核心人才稳定性与敬业度
