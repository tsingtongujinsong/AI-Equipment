# 战略意图

## 愿景

成为细分行业领先的数智化装备与产线升级方案提供商。

## 使命

以“软硬一体+数据驱动”能力，帮助客户实现更高效率、更高质量、更低综合成本的生产运营。

## 战略定位

从“设备制造商”升级为“智能制造解决方案商”。

## 战略北极星（3-5年）

- 在目标细分行业形成可复制的行业方案包
- 建立稳定的标杆客户群与复购机制
- 构建“设备+软件+服务”协同收入结构

## 战略取舍（做什么 / 不做什么）

### 做什么

- 聚焦中高端场景与高价值工艺环节
- 优先投入可复用、可规模化的产品与方案能力
- 以客户业务价值（效率、良率、OEE）驱动方案设计

### 不做什么

- 不做低附加值、纯价格竞争型项目
- 不做长期不可复用的重度定制开发
- 不以短期收入牺牲长期产品化方向

## 阶段性战略路径

- **阶段1（0-12个月）**：完成组织起盘、首个标杆场景验证
- **阶段2（1-3年）**：复制行业方案、提升毛利与交付效率
- **阶段3（3-5年）**：形成平台化与服务化经营能力
