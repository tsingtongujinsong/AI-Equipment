# 战略意图

## 愿景

成为子公司非标装备业务数智化升级的核心赋能引擎。

## 使命

围绕非标装备业务，建设可复用的软件、数据、算法、平台与服务能力，持续提升客户价值与经营效率。

## 战略定位

从“项目配套支持角色”升级为“业务增长与能力沉淀的数智化赋能中枢”。

## 部门边界

### 我们做什么

- 为子公司非标装备业务提供数字化、智能化能力底座
- 面向典型场景沉淀标准模块、软件工具、算法能力和运维服务
- 通过数据、软件和服务提升装备方案附加值与复购率

### 我们不做什么

- 不把装备本体作为部门产品规划对象
- 不替代子公司整体装备产品线的战略职责
- 不以新增机械本体型号作为部门核心成果

## 战略北极星（3-5年）

- 形成一套可复用的数智化能力模块体系
- 建立覆盖售前、交付、运维的数字化工具与平台能力
- 构建“软件授权 + 算法服务 + 运维服务 + 改造增购”收入结构

## 阶段性战略路径

- **阶段1（0-12个月）**：完成部门定位校准，落地首批高价值数智化场景
- **阶段2（1-3年）**：沉淀模块与平台能力，提升复用率与项目经营质量
- **阶段3（3-5年）**：形成平台化、服务化、数据化的持续经营模式
