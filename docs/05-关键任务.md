# 关键任务

## 年度四项关键任务

1. 标杆客户突破
2. 核心产品平台化
3. 交付能力提升
4. 服务体系搭建

## 任务拆解与交付件

### 1）标杆客户突破

- 完成目标客户池分层与攻坚名单
- 形成首个标杆项目完整案例（方案、实施、验收、复盘）
- 交付件：客户分层清单、标杆案例包、复购机会清单

### 2）核心产品平台化

- 明确标准模块清单与版本路线
- 在新项目中提升标准模块复用率
- 交付件：模块清单、版本路线图、复用率月报

### 3）交付能力提升

- 固化项目全流程模板与质量门禁
- 建立关键问题闭环机制（缺陷、变更、延期）
- 交付件：交付SOP、质量门禁表、项目复盘库

### 4）服务体系搭建

- 建立售后响应等级与巡检机制
- 形成运维服务包与续约流程
- 交付件：服务目录、响应SLA、续约经营台账

## 年度节奏（Q1-Q4）

- **Q1**：完成目标聚焦、组织对齐、首批机会验证
- **Q2**：完成核心模块首发与首个项目立项
- **Q3**：完成标杆项目交付与标准模板固化
- **Q4**：完成年度复盘并输出下一年度任务清单

## 闭环标准

- 每项任务均需具备：负责人、里程碑、量化结果、复盘结论
- 月度看执行，季度看结果，年度看可复制性
