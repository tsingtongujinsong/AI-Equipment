# 业务设计

- **业务组合**：拳头行业做深（1-2个）+ 邻近行业复制（2-3个）。  
- **价值链**：前端方案咨询—中端装备交付—后端运维优化。  
- **商业模式**：硬件毛利 + 软件授权 + 运维服务 + 改造增购。  
- **渠道策略**：直销大客户为主，区域集成商协同为辅。  
- **关键指标**：高端订单占比、项目毛利率、复购率、交付周期、服务收入占比。  

## 定位方式

作为跨行业机会池（能源、化工、冶金、交通装备、军工配套等）。

## 切入策略

先从“存量产线改造、节能降耗、安全合规、少人化/无人化”这类确定性需求切入。

## 项目打法

优先做1-2个央国企标杆项目，形成可复制模板，再区域扩张。

- 商机阶段：72小时输出《场景诊断与ROI初判》。  
- 方案阶段：2周内完成“技术方案+交付计划+风险清单”。  
- 交付阶段：按“标准模块80% + 定制开发20%”执行，控制范围蔓延。  
- 验收阶段：以UPH、良率、OEE、MTBF作为共同验收指标。  

## 经营要点

适配其采购流程（招投标、资质、信创/国产化要求、验收规范、回款周期管理）。

- 订单结构：优先高毛利、可复制、回款条件清晰项目。  
- 毛利管理：报价评审前置，项目全周期滚动核算毛利偏差。  
- 现金流管理：严格节点回款，控制在制项目与应收账款账龄。  
- 复购经营：验收后90天内完成复盘并推动二期增购或服务续约。
