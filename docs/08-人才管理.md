# 人才管理

## 人才策略

围绕“行业理解 + 技术能力 + 业务协同”构建复合型人才队伍。

## 关键岗位配置

重点引进与培养：

- 行业工艺专家
- 系统架构师
- 项目经理
- 售前方案团队
- AI/工业软件工程师

## 人才获取路径

- 内部转型培养：机械/电控骨干向数字化方向升级
- 外部招聘引进：核心岗位优先引进有落地经验人才
- 校企合作储备：建立算法与软件后备梯队

## 人才评估维度

- 专业能力：技术深度与工程化能力
- 场景能力：行业工艺理解与问题抽象能力
- 协作能力：跨团队沟通与推进能力
- 成长能力：学习速度与复盘能力

## 培养与发展

- 新人90天融入计划：业务认知、流程训练、导师带教
- 岗位能力地图：按岗位定义L1-L5能力标准
- 项目制实战培养：以真实项目驱动能力升级
- 双通道发展：技术序列与管理序列并行

## 绩效与保留

- 绩效看“结果+过程”：业务结果、复用贡献、协作表现
- 对关键人才设置中长期激励与成长计划
- 通过挑战性项目与明确晋升路径提升留存

## 人才健康指标

- 关键岗位到岗率
- 核心人才流失率
- 人均产出与项目胜任率
- 内部晋升占比与梯队覆盖率
