# 人才管理

## 人才策略

围绕“行业理解 + 数字技术 + 业务协同 + 服务意识”构建复合型人才队伍，重点补齐软件、数据、算法、平台和实施服务能力。

## 关键岗位配置

重点引进与培养：

- 行业场景专家
- 系统/平台架构师
- AI/工业软件工程师
- 数据与算法工程师
- 售前方案团队
- 项目经理/实施经理
- 运维与客户成功人员

## 人才获取路径

- 内部转型培养：机械/电控/工艺骨干向数字化方向升级
- 外部招聘引进：核心岗位优先引进有落地经验人才
- 校企合作储备：建立算法、软件、数据方向后备梯队
- 生态联合培养：与合作伙伴共建方法论与交付能力

## 人才评估维度

- 专业能力：技术深度与工程化能力
- 场景能力：行业工艺理解与问题抽象能力
- 协作能力：跨团队沟通与推进能力
- 服务能力：客户响应、问题闭环、持续优化意识
- 成长能力：学习速度与复盘能力

## 培养与发展

- 新人90天融入计划：业务认知、流程训练、导师带教
- 岗位能力地图：按岗位定义L1-L5能力标准
- 项目制实战培养：以真实场景与真实项目驱动能力升级
- 双通道发展：技术序列与管理序列并行
- 知识沉淀要求：项目结束后输出模块经验、案例或方法模板

## 绩效与保留

- 绩效看“结果+过程”：业务结果、复用贡献、协作表现、客户成功
- 对关键人才设置中长期激励与成长计划
- 通过挑战性项目与明确晋升路径提升留存
- 对能推动跨项目复用和平台沉淀的人才重点激励

## 人才健康指标

- 关键岗位到岗率
- 核心人才流失率
- 人均产出与项目胜任率
- 内部晋升占比与梯队覆盖率
- 知识输出量与复用贡献度
