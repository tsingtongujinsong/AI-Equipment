# 预算与绩效

## 预算管理原则

- 资源向核心数字能力、平台模块与高价值服务场景倾斜
- 预算与阶段目标绑定，按里程碑动态调整
- 同时管理收入、复用价值、服务收入与现金流安全

## 年度预算框架（示例）

| 预算类别 | 参考区间 | 说明 |
|---|---:|---|
| 人力成本 | 300-500万 | 核心团队建设 |
| 数字化研发与测试环境 | 50-100万 | 服务器、工业相机、边缘设备、测试工装 |
| 软件许可 | 10-30万 | 开发、仿真、数据与平台工具 |
| 市场推广 | 20-50万 | 展会、案例、品牌物料 |
| 差旅培训 | 10-20万 | 客户拜访、实施支持与人才培养 |
| 专利法务 | 5-10万 | 知识产权与合规 |
| **合计** | **395-710万** | 按阶段动态分配 |

## 资源分配机制

- 优先支持：标杆场景、平台化模块、高复购场景
- 审批门槛：新增投入需对应业务价值与回收路径
- 滚动复盘：月度执行、季度纠偏、年度复盘

## 绩效体系

绩效从“项目收入导向”升级为“收入 + 服务 + 复用 + 客户成功 + 能力沉淀”。

### 关键指标（建议）

- 收入：签约额、交付额、数字化增值收入占比
- 服务：运维收入、续约率、服务响应达标率
- 复用：标准模块复用率、重复开发下降率
- 客户成功：NPS、关键场景达标率、故障响应时效
- 经营质量：毛利改善、回款率、账龄结构
- 能力沉淀：模块版本发布、案例沉淀、知识库更新

## 绩效执行节奏

- 月度：经营与项目指标追踪
- 季度：绩效评估与资源重配
- 年度：绩效复盘与激励兑现
