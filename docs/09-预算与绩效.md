# 预算与绩效

## 预算管理原则

- 资源向战略赛道与高毛利产品倾斜
- 预算与阶段目标绑定，按里程碑动态调整
- 同时管理收入、毛利、回款与现金流安全

## 年度预算框架（示例）

| 预算类别 | 参考区间 | 说明 |
|---|---:|---|
| 人力成本 | 300-500万 | 核心团队建设 |
| 研发设备 | 50-100万 | 服务器、工业相机、测试工装 |
| 软件许可 | 10-30万 | 开发与平台工具 |
| 市场推广 | 20-50万 | 展会、案例、品牌物料 |
| 差旅培训 | 10-20万 | 客户拜访与人才培养 |
| 专利法务 | 5-10万 | 知识产权与合规 |
| **合计** | **395-710万** | 按阶段动态分配 |

## 资源分配机制

- 优先支持：标杆项目、平台化模块、高复购场景
- 审批门槛：新增投入需对应业务价值与回收路径
- 滚动复盘：月度执行、季度纠偏、年度复盘

## 绩效体系

绩效从“收入导向”升级为“收入 + 毛利 + 回款 + 复购 + 客户成功”。

### 关键指标（建议）

- 收入：签约额、交付额、行业拓展进度
- 毛利：项目毛利率、结构毛利改善
- 回款：回款率、账龄结构、坏账风险
- 复购：二期增购率、续约率
- 客户成功：NPS、关键场景达标率、故障响应时效

## 绩效执行节奏

- 月度：经营与项目指标追踪
- 季度：绩效评估与资源重配
- 年度：绩效复盘与激励兑现
