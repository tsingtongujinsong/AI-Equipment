# 业务设计

## 业务组合

- 拳头行业做深（1-2个）
- 邻近行业复制（2-3个）
- 存量客户升级改造与新增标杆客户并行

## 价值链设计

前端方案咨询 → 中端装备交付 → 后端运维优化

## 商业模式

- 硬件毛利
- 软件授权
- 运维服务
- 改造增购

## 客户与渠道策略

- 直销大客户为主，区域集成商协同为辅
- 客户分层经营：标杆客户 / 成长客户 / 现金流客户
- 优先行业：高景气、高自动化升级刚需、高复用潜力场景

## 切入策略

- 从“存量产线改造、节能降耗、安全合规、少人化/无人化”切入
- 采用“单机标杆 + 产线改造”双切入路径

## 项目打法

- 商机阶段：72小时输出《场景诊断与ROI初判》
- 方案阶段：2周内形成“技术方案+交付计划+风险清单”
- 交付阶段：标准模块80% + 定制开发20%
- 验收阶段：以UPH、良率、OEE、MTBF统一验收

## 经营要点

- 订单结构优先高毛利、可复制、回款条件清晰项目
- 报价评审前置，项目全周期滚动核算毛利
- 严格节点回款，控制在制项目与应收账款账龄
- 验收后90天内完成复盘并推动二期增购/续约
