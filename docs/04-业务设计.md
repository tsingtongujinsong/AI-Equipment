# 业务设计

## 业务定位

数智化装备部的业务不是销售装备本体，而是为子公司非标装备业务提供内部赋能能力，并形成可对客输出的数字化增值方案。

## 业务组合

- **内部赋能型业务**：售前方案工具、交付工具、数据平台、知识库、标准模块
- **对客增值型业务**：视觉质检、数据采集、远程运维、工艺优化、数字孪生展示与分析
- **存量升级型业务**：既有设备的联网改造、数据化改造、智能化升级

## 价值链设计

前端场景诊断 → 中端数字能力配置与实施 → 后端持续运维与数据优化

## 商业模式

- 软件授权
- 算法/应用模块收费
- 实施与集成服务
- 运维服务
- 改造增购

## 客户与服务对象

- **内部客户**：子公司销售、方案、研发、交付与售后团队
- **外部客户**：购买非标装备并需要数字化增值能力的终端客户

## 切入策略

- 先做对签单和交付最有帮助的高价值场景
- 优先切入“数据采集、视觉质检、远程运维、工艺参数优化”等标准化潜力高的方向
- 采用“单场景验证 → 模块标准化 → 多项目复用”路径推进

## 项目打法

- 商机阶段：快速输出《场景诊断与价值初判》
- 方案阶段：明确数字能力边界、接口责任与ROI逻辑
- 交付阶段：标准模块优先，定制开发受控
- 验收阶段：围绕效率、质量、稳定性、服务响应达成共识

## 经营要点

- 先证明数字能力对签单、毛利、复购的拉动价值
- 将部门经营重点放在复用率、服务收入和数据资产沉淀
- 与装备本体项目协同经营，但边界清晰、责任清晰
